# Hospital Management System

A Java-based Hospital Management System designed to simplify and automate daily hospital operations. The application enables efficient management of patients, doctors, appointments, and billing through a structured, object-oriented approach.

The system was developed as a console-based application using Java and follows Object-Oriented Programming (OOP) principles such as inheritance, encapsulation, abstraction, and polymorphism to ensure a modular, scalable, and maintainable architecture.

## 🚀 Features
- **Admin Authentication:** Secure login system for administrators.
- **Patient Management:** Add, update, search, and manage patient records.
- **Doctor Management:** Maintain doctor profiles, departments, and availability.
- **Appointment Scheduling:** Book and manage appointments between patients and doctors.
- **Billing System:** Generate and manage patient bills with accurate cost calculations.
- **File Handling:** Store and retrieve hospital records using Java file handling.
- **Object-Oriented Design:** Built using inheritance, encapsulation, abstraction, and polymorphism for better code organization and maintainability.
- **Console-Based Interface:** User-friendly menu-driven application for easy navigation.
